The pipeline

Step by step.

Customer asks a question
The customer types their question in natural language into the chat widget. No forms, no category selection. The AI understands intent from free text.
Natural language
RAG knowledge base lookup
The AI converts the question to an embedding and performs semantic similarity search across the knowledge base. Top-matching articles are retrieved and ranked by similarity score.
RAG Semantic search
Confidence threshold check
If the best match scores above the confidence threshold (configurable, default 65%), the AI drafts an answer and sends it. Below the threshold, the question escalates. The customer sees a live confidence ring during this process.
High confidence → answer Low confidence → escalate
Ticket creation and routing
Escalated questions become tickets. The LLM classifies the category, estimates priority, detects sentiment, and routes to the right team. All metadata is AI-generated — agents start with full context.
Auto-classified Auto-prioritized Sentiment tagged
Agent resolves with AI copilot
The agent gets an AI-drafted reply, similar resolved tickets, and live confidence rings for each classification dimension. The copilot is a suggestion engine — the agent always has final control.
AI Copilot
Knowledge base update (with admin gate)
When a ticket is resolved, the AI drafts a new KB entry from the conversation. It goes into a pending review queue. An admin must explicitly approve it before it's published. No auto-publish of AI content — ever.
Pending admin approval

Key design principles

Why it's different.

Human in the loop
Every AI-generated KB entry requires admin approval. Agents review AI drafts before sending. Confidence thresholds are tunable.
Closed-loop learning
Each resolved ticket makes the system smarter. The KB grows organically from real issues — not manually curated FAQs.
Transparent confidence
Every AI decision shows its confidence score visually. No black-box answers — customers and agents always know how certain the AI is.
